KAM Setup Guide

Get Mica CRM installed and your WhatsApp connected in under 5 minutes.

⬇️ Download Mica CRM

Mac (Apple Silicon & Intel) · Latest version

🍎 Download for Mac (.dmg) 🪟 Windows (.exe)

Built and distributed by the Mica tech team · @mica.rent accounts only

1

Install the app

Mac: Open the downloaded .dmg file. Drag the Mica CRM icon into your Applications folder. Eject the disk image.

Windows: Run the .exe installer and follow the prompts. A desktop shortcut will be created automatically.

⚠️
Mac Gatekeeper notice: On first launch, macOS may say "cannot be opened because it is from an unidentified developer." Right-click the app icon → Open → click Open again to allow it. You only need to do this once.
2

Make sure Google Chrome is installed

Mica CRM uses your existing Chrome to power the WhatsApp connection — no extra downloads needed. If you don't have Chrome, download it here.

💡
Chrome must be at its default location (/Applications/Google Chrome.app on Mac). If you moved it, put it back.
3

Sign in with your Mica Google account

Launch Mica CRM from your Applications folder. The login screen will appear automatically.

Click "Sign in with Google" and choose your @mica.rent Google account. Non-Mica accounts are blocked by default.

✅
Your login stays active — you won't need to sign in again unless you log out manually.
4

Connect your WhatsApp

After login, you'll land on the board screen. Look for the "Connect WhatsApp" button in the top-right corner and click it.

A QR code will appear. Open WhatsApp on your phone and scan it:

iPhone: WhatsApp → Settings → Linked Devices → Link a device → scan
Android: WhatsApp → ⋮ menu → Linked Devices → Link a device → scan

🔄
The QR code expires after ~20 seconds — refresh it by clicking the code if it fades out. Your session is saved after the first scan so you won't need to re-scan on relaunch.
5

Understand the Kanban board

Every WhatsApp contact you message (or who messages you) appears as a card on the board. Drag cards between columns to track where each lead is in your process:

Drag and drop cards directly between columns, or click a card to open the conversation and move it from there.
6

Chat and manage leads

Click any contact card to open the conversation panel on the right. You can:

  • 📨 Send and receive WhatsApp messages in real time
  • 📝 Add private notes visible only inside the CRM
  • 🏷️ Move the contact to a different pipeline stage
  • 📋 Use message templates to reply faster
  • 🔴 Unread badge — goes away when you open the chat
7

Tips & things to know

  • 🔗 You can keep using WhatsApp on your phone while the CRM is open — it runs as a linked device.
  • ⚡ Messages arrive instantly via real-time sync — no need to refresh.
  • 🔒 Your WhatsApp session is stored on your machine only. Reinstalling the app erases it (you'll need to scan again).
  • 🛑 If the green dot turns red, click "Reconnect" in the top bar — your session may have expired.

Admin Setup Guide

Full visibility over all KAMs, conversations, and pipeline — from one account.

Admin account: julian@mica.rent
The admin role is automatically granted on sign-in. You get a purple Admin button in the top bar that no one else sees. No extra setup needed.
1

Install exactly like a KAM

Download and install Mica CRM using the same steps as a regular KAM (see the KAM tab). The app is identical — your special permissions activate automatically when you log in with julian@mica.rent.

Same app, admin powers unlocked on login

🍎 Download for Mac (.dmg)
2

Sign in with julian@mica.rent

Launch the app and click "Sign in with Google". Use your julian@mica.rent account. Upon login you'll see a purple Admin button appear in the top navigation bar.

Click the purple Admin button in the top-right corner to enter the admin view. You'll see an overview of all KAMs and their live stats:

All KAMs

See who's online, their WhatsApp connection status, and how many contacts they manage.

🔴

4

Read any conversation

Click on any KAM card → then any contact → and the full conversation history opens in read-only mode. You can see everything but won't accidentally send a message on a KAM's behalf.

👀
Read-only: The admin view is observation only. To send a message as a KAM you'd need to log in as that KAM. This protects against accidental interference.
5

Manage user roles

Need to promote a KAM to admin, or revoke access? In the Admin Dashboard go to a user's card and use Change Role. Roles available:

  • kam — default role, can only see their own pipeline
  • admin — full visibility over all KAMs, user management
6

Your own WhatsApp (optional)

You can optionally connect your own WhatsApp number exactly like a KAM — it's not required for admin duties. Connect it from the regular board view (click Back from the admin dashboard).

7

Initial setup checklist (first time only)

Before distributing the app to KAMs, complete these one-time steps:

  • 1. Create a Google OAuth Client ID
    Go to console.cloud.google.com → APIs & Services → Credentials. Create an OAuth 2.0 Client ID for a Web application. Add http://localhost:3001 as an authorized redirect URI. Copy the Client ID.
  • 2. Add the Client ID to the app config
    Open a terminal in the project folder and run: 
    echo 'GOOGLE_CLIENT_ID=your_client_id_here' > backend/.env
echo 'VITE_GOOGLE_CLIENT_ID=your_client_id_here' > frontend/.env
    Replace your_client_id_here with the real value.
  • 3. Rebuild and repackage
    Run npm run package:mac from the project root. The new .dmg in the release/ folder will have the Client ID baked in. Distribute this file to KAMs.
  • 4. Tell KAMs to download & scan once
    Share this guide page with each KAM. Their WhatsApp session persists after the first QR scan.
🔑
Keep the .env files private — never commit them to git. They contain your Google Client ID which should not be shared publicly.
8

Where is the data stored?

Each KAM's data lives on their own machine:

  • Mac: ~/Library/Application Support/Mica CRM/data/
  • Windows: %APPDATA%\Mica CRM\data\

The SQLite database (mica-crm.db) and WhatsApp sessions (wa_sessions/) are in that folder. As admin you can read any KAM's data when they have the app open — your admin dashboard connects to the backend running on their machine.

☁️
In the future, a shared cloud database could give you persistent cross-machine access. For now, each install is self-contained.
